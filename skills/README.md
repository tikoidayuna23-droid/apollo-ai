# Apollo Agent Skills (Future Roadmap)

This directory is prepared for future modular capability extensions in subsequent phases of Apollo:

- **Web Research & Grounding**: Live query augmentation and citation parsing
- **PC & OS Automation**: Local system commands and launcher hooks (Phase 2+)
- **MCP Integration**: Model Context Protocol servers and client adapters
- **File System & Multi-modal Analysis**: Document and asset processing
- **Sub-agents**: Autonomous delegation pipelines

In **Phase 1**, Apollo provides built-in tools (`calculator`, `save_memory`, `search_memory`) registered via `src/tools/registry.ts`.
